# RoboCourier web remote

Phone remote for the RoboCourier robot over Bluetooth LE (HM-10 module), built on Web Bluetooth. Safari on iPhone has no Web Bluetooth, so open the published page in the free **Bluefy** browser from the App Store.

Copied from the `web/` folder of the private RoboCourier repo. Open the page with `?mock` to use a fake robot. Tests: `npm test`.
